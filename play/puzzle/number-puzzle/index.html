How to Play Number Puzzle

The board contains numbered tiles and one empty space. Move a tile into that space until every number is arranged from smallest to largest, with the empty space in the final position.

  1. Choose a 3×3, 4×4, or 5×5 board.
  2. Click or tap a numbered tile beside the empty space.
  3. On a keyboard, use the arrow keys to move the empty space.
  4. Continue until the numbers are in ascending order.

Number Puzzle Tips

  • Build the first row before focusing on lower rows.
  • Avoid breaking tiles that are already correctly placed.
  • Think two or three moves ahead near the end.
  • Use a smaller board to learn the movement pattern.

About the Number Puzzle Game

Number Puzzle is a classic sliding-tile puzzle built around ordering, spatial reasoning, and move planning. This browser version runs entirely on your device, so you can play the number puzzle online without installing an app or downloading game files.

The 3×3 board is a quick introduction, while 4×4 and 5×5 layouts add more possible positions and require longer sequences of moves. Every new game is generated from the solved board using valid moves, which keeps the shuffled puzzle solvable.

Number Puzzle FAQ

Is this Number Puzzle free to play?

Yes. The game runs free in a modern browser and does not require a download, account, or signup.

How do I win the Number Puzzle?

Arrange every numbered tile in ascending order from the top-left of the board, leaving the empty space in the bottom-right position.

Can I play on a phone?

Yes. Tap adjacent tiles or use the on-screen directional controls. The board automatically scales to fit smaller screens.

Are the shuffled puzzles solvable?

Yes. New puzzles are created by making legal moves from a solved board, so each generated position has a valid path back to the solution.
