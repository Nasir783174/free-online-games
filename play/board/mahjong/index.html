How to Play Mahjong

  1. Select an open tile. An open tile has no tile sitting above it and at least one free side.
  2. Select another open tile with the same symbol.
  3. Matched tiles disappear from the board and reveal new moves.
  4. Clear every tile to win.

Scoring

Each pair earns 100 points. Faster consecutive matches add a small streak bonus. Hints reduce your score by 25 points and shuffles reduce it by 50 points.

About This Mahjong Game

This browser game uses the familiar Mahjong solitaire format rather than the four-player table game. The objective is to remove matching tile pairs from a layered layout. The challenge comes from choosing pairs in an order that keeps future tiles accessible.

The board is generated entirely in your browser with HTML, CSS, and JavaScript. No account, installation, or download is required.

Mahjong Tips and Strategy

  • Prioritize matches that uncover stacked tiles.
  • Free long horizontal rows from the outside inward.
  • Avoid matching the first pair you see if another identical tile would unlock more options.
  • Use the hint button only when you are genuinely stuck.
  • Shuffle when no open matching pair remains.

Mahjong FAQ

Is this Mahjong game free?

Yes. The game runs free in your browser with no login or download.

Which tiles can I select?

You can select a tile when it has no tile directly above it and either its left or right side is free.

What happens if there are no matching moves?

Use Shuffle to rearrange the remaining tile symbols while keeping the current board positions.

Does Mahjong work on mobile?

Yes. The layout adapts to smaller screens and all gameplay actions work with touch.
